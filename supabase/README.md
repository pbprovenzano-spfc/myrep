# Supabase — My Rep

1. Abra o projeto [Supabase](https://supabase.com/dashboard) (`raodkkzzxyhxucscuoct`).
2. **SQL Editor** → cole e execute [`schema.sql`](schema.sql).

4. Na raiz do projeto: `npm run seed:supabase` (sobe JSONs + assets).
